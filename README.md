# Wine Quality Prediction

## Project Overview
This project predicts wine quality using Machine Learning techniques.

## Dataset
Wine Quality Dataset

## Steps Performed
- Data Loading and Analysis
- Missing Value Check
- Correlation Analysis
- Binary Classification (GOOD/BAD Wine)
- Logistic Regression
- Feature Scaling
- KNN and Decision Tree Comparison
- Hyperparameter Tuning using GridSearchCV
- Feature Importance Analysis

## Best Model
K-Nearest Neighbors (KNN)

## Results
- Accuracy: 90.94%
- Precision: 73.68%
- Recall: 59.57%
- F1 Score: 65.88%

- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
